Operator rules

  • First test with the wheels off the ground.
  • START runs the robot only from READY. In FINISHED, START only returns to READY; the next START runs.
  • START is refused while running, while calibrating (up to 3 s after power-up, or after Button 2) and in FAULT (send RESET first).
  • STOP is always accepted: it ends a run in FINISHED, and does nothing when the robot is not running. This button, the Escape key and the GP20 button all stop the robot.
  • RESET works only from FAULT or FINISHED, back to READY with the motors braked.
  • After a GP20 start the robot is running, so a dashboard START is refused; STOP still works. GP20 held for 2 s is RESET.
  • TEST=1 images ignore START, STOP and RESET until an S5 test step arms the controller.
  • "queued" means S5 received the command, not that it acted. S5's verdict is on the robot's console only (EVT 0x65 a=opcode b=1 or 0) until the event channel is built; the S5 panel shows the state change. "rejected" means S1 refused the command or could not hand it to S5.
  • A command sent while the robot is offline is lost: no ack.
